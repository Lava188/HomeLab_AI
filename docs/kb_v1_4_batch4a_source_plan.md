# KB v1.4 Batch 4A Source Plan

## Scope

This plan prepares authoritative, patient-facing source URLs for the future KB v1.4 Batch 4A medical/lab knowledge expansion. It does not ingest KB items, modify runtime logic, build retriever artifacts, enable semantic retrieval by default, or change package recommendation gates.

Batch 4A should remain RAG-first and source-backed. Simulated/demo data must not be used as medical knowledge. Any future KB item derived from these sources must carry provenance, source URL, source family, review status, safety notes, and runtime promotion flags.

## Source Selection Rules

- Use only official or patient-facing sources from allowed domains: `medlineplus.gov`, `niddk.nih.gov`, `nhs.uk`, `nice.org.uk`, `cdc.gov`, `who.int`.
- Prefer MedlinePlus and NIDDK for lab-test explainers, preparation, and result-boundary language.
- Prefer NHS for general blood-test patient experience and result workflow.
- Use NICE only where urgent clinical guideline context is needed.
- Do not use blogs, forums, SEO health pages, private clinics, or lab vendor marketing pages as primary KB sources.
- Do not promote test results as diagnosis. Result explanations must say results need clinical context, symptoms, history, medication context, reference ranges, and health professional review.
